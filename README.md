# Edisam School Website

Next.js 15 (App Router, TypeScript) + Tailwind CSS v4.

## Run it
1. npm install
2. npm run dev
3. Open http://localhost:3000

## Edit your content
Open `lib/site.ts`: phone, email, WhatsApp number, domain, fees, news and staff.
Contact map: `MAP_SRC` in `app/contact/page.tsx`.
Enquiry form email: see the TODO in `app/api/enquiry/route.ts`.
